# Notes for future changes

Keep the delegation policy conservative. OpenCode is the worker for well-defined implementation tasks; Claude Code remains responsible for architecture, ambiguous work, and final review.

When changing `SKILL.md`, retest at least once in an Opus session and once in a Sonnet session.

## Commits

Write all commit messages in English using Conventional Commits (e.g. `feat: ...`, `fix: ...`, `docs: ...`).
